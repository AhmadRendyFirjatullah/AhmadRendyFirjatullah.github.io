Penjelasan Project

Aplikasi Absensi Karyawan merupakan sistem berbasis web menggunakan framework Laravel yang dirancang untuk mempermudah proses pencatatan kehadiran karyawan secara digital, cepat, dan terkomputerisasi. Sistem ini membantu perusahaan dalam meningkatkan efisiensi pengelolaan data absensi agar lebih akurat dan mudah dipantau.

Fitur utama aplikasi meliputi absensi masuk dan pulang menggunakan scan QR Code, manajemen data karyawan, riwayat kehadiran, rekap absensi, serta dashboard monitoring untuk memantau data kehadiran secara real-time. Aplikasi ini juga dirancang responsif sehingga dapat digunakan dengan baik melalui perangkat desktop maupun mobile.
